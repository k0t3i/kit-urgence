# Kit d'urgence

Simulateur 3D pour préparer un kit d'urgence adapté à votre foyer : réserve à la maison de 72 h à 3 semaines, un sac d'évacuation par personne, et des listes à cocher en PDF.

Site : https://k0t3i.github.io/kit-urgence/

Cette animation a une visée de sensibilisation. Elle ne remplace pas les consignes officielles des autorités.
